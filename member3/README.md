# Browser Tab and Session Manager

## Project Description
The Browser Tab and Session Manager is a C-based project that manages browser tabs and recently closed tabs.

## Objectives
- Open a new browser tab.
- Close an existing tab.
- Switch between tabs.
- Display all open tabs.
- Restore recently closed tabs.

## Data Structures Used
1. Doubly Linked List – To manage open browser tabs.
2. Stack – To store and restore recently closed tabs.

## Programming Language
C
